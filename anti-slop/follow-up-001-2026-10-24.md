# Hasil perbaikan audit portfolio

Tanggal: 24 Oktober 2026. Pengguna mengizinkan perbaikan semua prioritas audit. Kontribusi pribadi dan URL proyek ditunda atas jawaban pengguna “nanti ya”; visual Spotify Clone juga menyusul.

## Perubahan berdasarkan nomor audit

| Temuan | Hasil |
| --- | --- |
| 1. Accordion terlalu sempit | Maksimal lima gambar, gambar aktif mendapat bobot 16 dibanding 1 untuk setiap panel lain. Container kecil menampilkan satu gambar utuh. |
| 2. Tidak ada pembesaran | Dialog native dengan Previous/Next, keyboard panah, Escape, pemulihan fokus, fit/full size dan akses gambar penuh. Scroll halaman terkunci saat dialog terbuka. |
| 3. Geometri mobile berubah | Placeholder dan galeri memakai variabel CSS yang sama. Tinggi terukur pada mobile: 364 px sebelum dan sesudah komponen dimuat. |
| 4. Cover login | EagleJeans membuka owner dashboard; ArthaBooks membuka dashboard. Login dan layar berulang tidak dimasukkan ke pilihan utama. |
| 5. Treatment screenshot | Jenis web/phone/document eksplisit, rasio dipertahankan. Galeri ponsel mendapat stage 400 px. Aset baru memiliki preview serta versi penuh yang dimuat saat pembesaran. Resolusi sumber EG7/EG8 tetap terbatas; sumber yang lebih besar belum diberikan. |
| 6. Hover dan discoverability | Hover tidak mengganti pilihan. Selector bernomor, label layar aktif, nama proyek pada grup dan kontrol keyboard tersedia. |
| 7. Bukti dan kontribusi proyek | GitHub tersedia di footer dan ringkasan. Dukungan URL per proyek sudah disiapkan. Tautan demo/repository spesifik dan detail kontribusi menunggu pengguna; tidak ada klaim atau URL yang dikarang. |
| 8. Hierarki konten | Featured: EagleJeans, ArthaBooks, ReuseMart. Proyek lain di More Work dalam dua kolom maksimum. Work muncul sebelum Process. Spotify diberi status In progress dan tidak memakai visual pengganti. |
| 9. llms.txt | File Markdown tersedia di public dan dist, metadata describedby serta tipe konten Cloudflare disiapkan. Rewrite global dihapus karena navigasi memakai fragmen. |
| 10. Ketergantungan JavaScript | Ringkasan statis /index.md dibuat dari data proyek saat build. Head menautkan versi Markdown; noscript menyediakan profil singkat, kontak dan akses ringkasan. Aplikasi tetap React client-side; tidak ada migrasi framework atau prerender penuh. |
| 11. Kegagalan pemuatan | Indikator pemuatan gambar, pesan gagal dengan retry, dan error boundary lazy gallery dengan reload. |

## Verifikasi dan delivery gate

- PASS, build: TypeScript dan Vite berhasil membangun output produksi, termasuk llms.txt, index.md, _headers dan _redirects.
- PASS, lint: ESLint tanpa kesalahan atau peringatan.
- PASS, R-03/C-4: pengujian build produksi pada 1440, 768, 390 dan 360 px tidak menemukan overflow horizontal halaman.
- PASS, C-2/R-26: pemilihan screenshot, keyboard panah, pembesaran, next/previous, full-size, Escape dan pemulihan fokus berhasil pada empat viewport.
- PASS, R-27: kegagalan permintaan gambar disimulasikan, pesan gagal muncul dan retry berhasil memuat gambar.
- PASS, kestabilan placeholder: permintaan modul galeri ditahan, tinggi sebelum/sesudah pada 390 px tetap 364 px.
- PASS, pemuatan sesuai kebutuhan: tidak ada permintaan gambar versi penuh sebelum Enlarge; permintaan baru terjadi sesudah dialog dibuka.
- PASS, deep link: membuka /#reusemart menempatkan proyek di area viewport yang terlihat.
- PASS, endpoint lokal: /llms.txt dan /index.md berstatus 200 dengan isi teks yang diharapkan. Header khusus Cloudflare belum dapat dibuktikan oleh Vite preview.
- PASS, runtime: tidak ada pageerror selama pengujian empat viewport.
- PASS, C-1/C-3: accordion dipertahankan atas preferensi pengguna; proporsi baru memberi ruang untuk membaca produk. Palet, font, radius dan grayscale panel nonaktif mengikuti arah desain yang sudah ada. Tidak ada ilustrasi atau screenshot buatan.
- PASS, C-5: tidak menambahkan angka performa, kontribusi personal, status produksi atau URL proyek tanpa sumber. Data proyek yang sudah ada tetap dipertahankan; bukti pendukungnya menunggu pengguna.
- BELUM DIVERIFIKASI: seluruh gate website, pembaca layar nyata, semua pasangan kontras, semua tautan eksternal dan kondisi jaringan. Ini bukan sertifikasi aksesibilitas menyeluruh.
- BELUM DIVERIFIKASI: skor Lighthouse terbaru dan perilaku endpoint pada deployment Cloudflare setelah perubahan. Tidak ada push atau deploy dalam pekerjaan ini.

Hasil pengujian mesin: `verification/results.json`. Screenshot browser produksi tersedia di `verification/`, termasuk desktop, mobile, ReuseMart dan lightbox. Script uji: `scripts/check-gallery.cjs` (set GALLERY_PRODUCTION=1 untuk output dist).

Penghapusan rewrite global mengikuti dokumentasi [Cloudflare Redirects](https://developers.cloudflare.com/pages/configuration/redirects/) dan [Serving Pages](https://developers.cloudflare.com/pages/configuration/serving-pages/): redirect dapat mendahului aset, sedangkan fallback SPA bawaan melayani root untuk path tanpa aset statis. Sesudah deploy, periksa kembali status, tipe konten dan isi kedua file teks sebelum menjalankan ulang Lighthouse.
