# Revisi visual galeri

Arahan pengguna: kembalikan hover accordion seperti React Bits, hilangkan kotak hitam pada screenshot ponsel, dan perbaiki capture EagleJeans yang terpotong.

- Hover mouse pada perangkat dengan hover/fine pointer kembali mengembangkan panel. Klik/tap, focus selector, keyboard dan dialog pembesaran tetap tersedia. Transisi 650 ms menghormati reduced motion.
- Capture ReuseMart memakai folder `mobile`, Gym memakai `_tools/raw_after`. Keduanya berupa layar mentah tanpa matte hitam dari komposit ponsel. WebP hanya dienkode dari capture tersebut; frame ponsel sekarang dibangun melalui CSS dengan rasio sumber 1180:2556.
- Panel web aktif memiliki bobot flex 12, ponsel 4, panel lainnya 1. Ponsel membutuhkan lebar lebih kecil; ruang yang tersisa memperlihatkan screenshot lain dengan lebih jelas.
- Latar steel datar diganti surface gelap dengan gradasi tipis pada panel ponsel untuk memisahkan tepi perangkat dari kartu. Kontrol kotak besar diganti selector bergaris bawah, dengan hit area tetap 44 px.
- EG8.png memang hanya 282×526 dan sudah berhenti di bagian Ukuran. Tidak ada bagian bawah yang dapat dipulihkan dari sumber itu. EG8 diganti oleh Production report (EG3) pada pilihan galeri; sumber aslinya tidak diubah. Scan barcode (EG7) tetap membuktikan tampilan PWA mobile dan ditampilkan dengan rasio sumbernya.

## Validasi

- PASS: TypeScript, build Vite dan ESLint.
- PASS: hover mengubah pilihan dan animasi panel benar-benar memperbesar lebar panel pada browser dengan motion aktif.
- PASS: pengujian build produksi pada 1440, 768, 390 dan 360 px; tidak ada overflow horizontal.
- PASS: keyboard, dialog, next/previous, Escape, pengembalian fokus dan mode full size.
- PASS: placeholder dan hasil akhir mobile sama-sama 340 px; tidak ada perubahan tinggi pada batas lazy component yang diuji.
- PASS: simulasi gambar gagal dan retry; file penuh hanya dimuat ketika diperbesar; deep link proyek.
- PASS: tidak ada pageerror dalam pengujian; screenshot ReuseMart dan Gym diperiksa secara visual untuk memastikan matte persegi hilang dan layar tetap utuh.
- BELUM DIUJI: Lighthouse baru dan hasil setelah deploy. Tidak ada push/deploy.

Hasil mesin berada di `verification/results.json`. Preview terbaru: `verification/reusemart-phone-desktop.png`, `verification/gym-desktop.png`, `verification/gym-mobile.png`, dan `verification/hover-phone.png`.

Referensi interaksi: [React Bits Accordion Gallery](https://reactbits.dev/components/accordion-gallery). Implementasi tetap memakai komponen lokal dan transisi CSS; tidak menambahkan GSAP atau dependency baru.
