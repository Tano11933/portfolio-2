# Audit konten dan desain portfolio

Tanggal: 2 November 2026. Sumber: working tree portfolio, screenshot asli Melodia, CV terbaru dua halaman, dan 11 PDF sertifikat/pelatihan yang diberikan pengguna. Ini audit lokal; deployment publik dan validitas online credential tidak diperiksa pada sesi ini.

## Perubahan yang sudah dikerjakan pada sesi ini

- Menambahkan lima screenshot Melodia: home, pencarian, detail playlist Fokus Ngoding, katalog admin, dan detail album mobile Ruang Tunggu.
- Alt diperiksa terhadap gambar asli. Contohnya, halaman admin yang dipilih sedang membuka tab Artist dan form tambah artis, bukan daftar/form album.
- Screenshot desktop dipertahankan sebagai capture penuh 16:10, termasuk player. Preview WebP maksimal 1600×1000; versi penuh maksimal 2400×1500. Versi penuh hanya dibuka saat diperlukan. Semua nama artis/album/akun pada capture berasal dari data demo menurut README sumber; tidak dipresentasikan sebagai pelanggan atau pengguna produksi.
- Tampilan mobile memakai frame iPhone yang sudah ada, tema layar gelap, dan mode contain untuk mempertahankan navigasi serta kontrol player. Tidak memotong bagian bawah screenshot agar sesuai frame.
- Nama tampilan menjadi Melodia (Spotify Clone), status In progress dipertahankan. Slug spotify-clone tetap agar tautan lama tidak rusak. Nama terkait pada llms.txt dan README diselaraskan.
- Informasi CV, kontribusi dan credential lainnya belum ditulis ulang pada implementasi: daftar di bawah adalah hasil audit untuk perubahan berikutnya.

## Penilaian umum

Fondasi tampilan dan galeri sudah lebih konsisten: hover/focus accordion, frame ponsel, pembesaran, retry, kontras kartu terang, dan cadangan ringkasan Markdown sudah tersedia. Pendidikan, GPA 3.54/4.00, masa internship Januari–Mei 2026, stack ArthaBooks, tiga role/13 permissions, lima laporan, dan UAT 32 responden/10 UMKM dengan skor 4.00/5.00 sesuai CV.

Namun konten belum seluruhnya sinkron dengan dokumen terbaru. Prioritas berikutnya adalah fakta pekerjaan, kontribusi personal, tautan bukti, dan struktur credential, bukan redesign total.

Jangan menafsirkan tanggal kontrak selesai sebagai bukti aplikasi tidak dipakai lagi; CV tetap menyebut 50–60 staff harian.
   Rujukan: C-5/R-17, ketepatan fakta.

2. **TINGGI: URL LinkedIn berbeda dengan CV terbaru.**
   Situs menggunakan `/in/gabrielgaetanoonenbaskara`; CV menyertakan hyperlink `/in/gabriel-gaetano-onen-baskara/`. Belum diuji apakah URL lama masih mengalihkan.

   Rujukan: C-2/C-5.

3. **TINGGI: ReuseMart belum menjelaskan kontribusi personal dan konteks tim.**
   Situs hanya menulis stack pada role, kemudian seluruh kemampuan aplikasi. CV sudah jelas menyebut tim tiga orang dan kontribusi checkout, pilihan pengiriman, reward points, verifikasi pembayaran, pembatalan otomatis dengan pengembalian poin; tiga laporan PDF; login/menu berbasis role, fitur kurir dan push notifications.

   Rujukan: C-5/R-17.

5. **SEDANG: sebagian skill belum memiliki tingkat penguasaan/konteks yang tepat.**
   CV menyebut Docker Compose foundational; situs belum memberi batas tersebut. Gemini/OpenAI API integration dan bahasa Indonesia/English intermediate belum ditampilkan. MongoDB, C, Java dan System design di situs tidak ada dalam daftar skill CV terbaru; ketidakhadiran di CV tidak membuktikan skill itu salah.
   Perubahan yang disarankan: fokuskan daftar utama pada skill yang dibuktikan proyek. Beri Docker label foundational, kelompokkan C/Java sebagai foundations bila tetap relevan, dan tambahkan API integration dengan konteks internship. Konfirmasi relevansi MongoDB sebelum menonjolkannya. Bahasa cukup satu baris di About.
   Rujukan: C-3/C-5/R-16.

Tanggal terbit dibaca dari PDF; status verifikasi online belum dikonfirmasi. Jangan menambahkan expiry yang tidak tertulis.
